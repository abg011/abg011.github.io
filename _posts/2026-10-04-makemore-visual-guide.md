An interactive visual guide to Andrej Karpathy’s makemore series, covering
layer shapes, initialization, BatchNorm, and manual backpropagation in Parts 1–4.

The guide is a self-contained HTML file in my PythonCode repository:

[Get the Makemore visual guide on GitHub](https://github.com/abg011/PythonCode/blob/master/scripts/AKarp/makemore/makemore-at-a-glance.html)

To use the interactive guide, download the file using GitHub’s **Download raw
file** button, then open the downloaded HTML file in your browser. The guide
runs locally; the GitHub link displays its source code.
